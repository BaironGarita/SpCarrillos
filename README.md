# 🌟 Iglesia Santidad Pentecostal - Carrillos Bajo de Poás

## 📱 Sitio Web Moderno y Responsivo

Este proyecto representa la presencia digital de la Iglesia Santidad Pentecostal en Carrillos Bajo de Poás, Costa Rica. Un sitio web moderno, elegante y completamente funcional diseñado para conectar con la comunidad y compartir el mensaje de fe.

## ✨ Características Principales

- 🎨 **Diseño Moderno y Elegante**

  - Interfaz limpia y profesional
  - Tipografía personalizada (Melodrama)
  - Animaciones suaves y atractivas
  - Totalmente responsivo para todos los dispositivos

- 🔒 **Sistema de Autenticación**

  - Panel de inicio de sesión seguro
  - Gestión de usuarios
  - Áreas protegidas para miembros

- 📱 **Optimización SEO**

  - Metaetiquetas optimizadas
  - Schema.org para mejor visibilidad
  - URLs amigables
  - Contenido estructurado

- 🎯 **Funcionalidades Clave**
  - Calendario de servicios
  - Información de contacto
  - Ubicación y direcciones
  - Horarios de servicios

## 🛠️ Tecnologías Implementadas

- HTML5
- Tailwind CSS
- JavaScript
- Alpine.js
- EmailJS
- AOS (Animate On Scroll)

## 🚀 Características Técnicas

- Diseño responsivo
- Optimización de rendimiento
- Animaciones suaves
- Integración con servicios externos
- Sistema de autenticación seguro

## 📅 Horarios de Servicios

- **Martes**: 7:00 PM - 8:30 PM

## 📍 Ubicación

100 metros norte del minisúper Don José, Carrillos Bajo, Poás, Costa Rica.
